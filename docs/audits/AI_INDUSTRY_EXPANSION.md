## Company ordering
Companies in the selected layer are ordered by whole-company public market capitalization converted to USD using Yahoo Finance FX quotes. This is not AI revenue, private-company valuation or investment quality. Missing values follow comparable public values, with stable alphabetic fallback. Private entities retain website access and do not receive fictional public tickers/values.

Only opening a layer fetches its small list. Known-symbol allowlist, maximum 12 symbols, 10-second provider request timeout, in-flight deduplication, bounded process cache and one-hour successful data cache. Provider failure returns unavailable values. Existing provider/data licensing requirements still apply.
